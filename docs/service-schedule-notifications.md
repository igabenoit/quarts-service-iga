# Avis d’horaire sur téléphone — Service

- « Publier cette semaine » prépare un avis **Nouvel horaire du Service** avec la date du lundi.
- Après une modification, « Publier les modifications » prépare un avis **Horaire du Service modifié**.
- Une modification privée ne déclenche aucun avis. Une publication identique non plus.
- Un appui sur la notification ouvre la semaine publiée dans le portail personnel; le code personnel reste requis si la session a expiré.

Les employés utilisent l’activation existante dans Discussion du Service → Notifications sur téléphone. Ils doivent ouvrir cette page une fois après cette mise à jour pour actualiser le composant de notifications. Les appareils déjà abonnés conservent leur abonnement et leur clé. Sur iPhone, utiliser le raccourci installé sur l’écran d’accueil.

Les avis concernent les employés actifs du Service ayant activé ce téléphone, y compris les employés sans quart dans la semaine. Les invités temporaires de la discussion et les comptes gestionnaires ne reçoivent pas ces avis. Aucun nom, détail de quart, note ou code personnel n’est envoyé dans la notification.

La file est enregistrée dans la transaction de publication. Le traitement respecte l’origine et la clé de chaque site, revérifie l’accès avant l’envoi, abandonne les publications retirées et réessaie les erreurs temporaires pendant au plus 24 heures. Plusieurs publications en attente pour la même semaine et le même appareil sont regroupées sur la dernière version. Les anciens horaires ne déclenchent aucun envoi rétroactif au démarrage. Une livraison au téléphone dépend des permissions, de la connexion et des réglages de concentration du téléphone.
