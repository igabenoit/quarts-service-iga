HORAIRE

Attribuer les quarts

Les affectations existantes sont conservées. Les quarts impossibles à couvrir restent visibles.

Un congé approuvé remet uniquement les quarts concernés à couvrir. Choisissez ensuite leur remplaçant dans la grille. Pour reprendre les congés déjà approuvés, utilisez le bouton ci-dessous.

Quart partagé : saisissez ici seulement la portion Service et l’autre portion dans son département, avec les fiches liées du même employé. Les deux horaires affichent la journée complète et ventilent les heures.

ÉQUIPE

Employés et disponibilités

Clique sur un employé pour modifier sa disponibilité permanente.

Autres postes possibles

Rang d’affichage : ordre dans chaque fonction, dans la liste et sur l’horaire imprimé. La gérante apparaît toujours avant les superviseurs. Priorité des quarts : ancienneté utilisée pour attribuer les heures souhaitées; un rang modifié passe avant la date d’ancienneté.

Un quart attribué manuellement peut déjà dépasser les heures souhaitées. Le « Maximum / semaine » reste une limite, même avec cette case cochée.

Disponibilités permanentes (chaque semaine)

Entre une plage comme 08:00-17:00. Laisse vide pour une journée toujours indisponible. Les changements s’appliquent aussi aux semaines futures.

Congés demandés pour la semaine affichée

Coche les journées à bloquer avant de générer l’horaire. Une affectation déjà faite pour ce jour sera retirée.

Absence à ses frais pendant le quart

Facultatif. Le quart complet reste affiché. Ne pas inscrire de motif médical.

Videz les deux heures pour retirer l’absence.

Décochez pour une absence temporaire, par exemple un arrêt maladie de longue durée. L’employé reste dans la liste.
