Essayer le formulaire en mode test

Les employés accèdent au formulaire depuis leur lien d’horaire, avec le code commun. Le nom est déclaré par l’employé; ce code ne confirme pas son identité.

Les demandes approuvées bloquent uniquement les dates et heures concernées dans toutes les semaines touchées. Les demandes en attente ne bloquent pas l’horaire. Les notifications par courriel sont limitées aux demandes de test pour le moment.

Notifications de test

Statistiques de toutes les demandes qui touchent la période choisie, indépendamment du filtre de statut ou de nom. Une demande qui chevauche deux semaines est comptée une seule fois. Les journées et heures portent sur la totalité de ces demandes approuvées; une journée complète n’est pas convertie en heures travaillées.
